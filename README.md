1. Опис проєкту:
    - REST API для зберігання та управління контактами. Включно механізмів аутентифікації та авторизації на основі JWT-токенів
2. Функціонал API
   * CRUD-операції: Повне управління контактами (створення, читання, оновлення, видалення).
   * Пошук: Пошук контактів за іменем, прізвищем або email.
   * Пошук за днями народження: Функція для знаходження контактів, у яких день народження протягом наступних 7 днів.
   * Аутентифікація: Захист API за допомогою JWT (пари токенів: access_token та refresh_token).
   * Авторизація: Кожен користувач має доступ лише до власних контактів.
3. Технології: FastAPI, SQLAlchemy, PostgreSQL, Alembic, Poetry
4. Запуск:
    * git clone <link>
    * створіть файл .env у корені проєкту. (Відправлено в особисті повідомлення)
    * poetry install
    * alembic upgrade head
    * uvicorn main:app --reload
