1. Опис проєкту:
    - REST API для зберігання та управління контактами з Fast API та PostgreSQL + Alembic
2. Менеджер залежностей:
    - Poetry
3. Конфігурація:
    - Файл .env з даними передається окремо
4. Запуск:
    - uvicorn main:app --reload
5. Перевірка функціональності:
    - Swagger UI (http://localhost:8000/docs)
6. Функціонал включає:
    - CRUD операції (включно з частковим і повним оновленням контактів)
    - Пошук контактів (за ім’ям, прізвищем, email)
    - Пошук контактів із днями народження у найближчі 7 днів
